# Аэропорт

Отдельный интерактивный прототип: поездка в аэропорт, очередь на парковке, быстрая подача и выход из очереди.

**[Открыть прототип](https://yageniia.github.io/airport-prototype/)**

Кнопки с цифрами над экраном переключают сценарии. В репозитории находится готовая статическая сборка для GitHub Pages. Карта использует MapLibre GL и OpenStreetMap.
